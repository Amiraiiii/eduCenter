**Статус:** ✅ Завершён

- [x] **Реальный API маршрут заявок (`/api/apply`):**
  - Серверная валидация (имя, номер телефона).
  - Интеграция с Telegram Bot API (отправка заявок в чат менеджеров при наличии `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`).

- [x] **Устранение заглушек в формах:**

  - `/contacts/page.tsx`: форма подключена к `/api/apply`, добавлена индикация загрузки, сброс полей и вывод сообщений об ошибках.
- [x] **Исправление навигации и багов в `Navbar.tsx`:**

## ✅ ЭТАП 4: Профориентационный тест (Quiz) и Премиум Редизайн (Anti-Neon)
**Статус:** ✅ Завершён

- [x] **Полный отказ от неоновых градиентов и дешевых свечений (Unslop & UI/UX Pro Max):**
  - Замена cyan/purple neon эффектов на глубокую графитовую палитру (Obsidian `#090a0d`, поверхности `#0f1117`, границы с микро-бликами).
  - Акценты: теплый матовый янтарь (Amber `#f59e0b`), платина, благородное серебро и изумрудный зеленый для статусов набора.
  - Серебряная интерактивная паутина в `HeroCanvas.tsx` с мягкой физикой и курсорным отталкиванием без едких цветов.
- [x] **Интерактивный Career Quiz (`CareerQuiz.tsx`):**
  - 4-шаговый тест с интерактивным прогресс-баром для определения идеальной профессии.
  - Мгновенный расчет зарплатной вилки, срока подготовки и % совпадения с профилем абитуриента.
  - Прямой переход к модалке записи или вызов AI-ассистента с предзаполненным вопросом о выбранной профессии.
- [x] **Аналитический калькулятор зарплатной траектории (`SalaryCalculator.tsx`):**
  - Интерактивное переключение грейдов: Junior (0-1 год) → Middle (1.5-3 года) → Senior (3-5+ лет).
  - Детальные зарплатные вилки в USD и UZS на рынке Узбекистана и Remote, списки необходимых технологий и компании-наниматели.
- [x] **Честный калькулятор беспроцентной рассрочки 0% (`InstallmentCalculator.tsx`):**
  - Расчет помесячной оплаты на 3, 6 или 12 месяцев через банки-партнеры (Anorbank, Uzum Nasiya, Paymart) без скрытых комиссий.
- [x] **Бегущая строка технологий и партнеров (`TechMarquee.tsx`):**
  - Плавный бесконечный тикер ключевого стека (Next.js 16, Python 3.12, Go, Docker, LangChain) и партнеров (Uzum, EPAM, Click, IT Park).
- [x] **Витрина реальных дипломных проектов (`StudentProjectsShowcase.tsx`):**
  - Демонстрация коммерческих дипломных кейсов студентов с метриками защиты и историями трудоустройства.
- [x] **Редизайн всех страниц сайта:**
  - Главная (`/`), каталог (`/courses`), детальная страница (`/courses/[slug]`), о нас (`/about`), контакты и FAQ (`/contacts`), модальное окно заявки (`ApplicationModal`) и чат (`AiAssistant`).
