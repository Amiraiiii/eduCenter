# 📚 Каталог курсов EduCenter (2026)

## 1. Frontend-разработка (React & Next.js)
- **Формат:** Офлайн (Ташкент) или Онлайн
- **Длительность:** 7 месяцев (3 раза в неделю по 2 часа)
- **Стек:** HTML5, CSS3/Tailwind, JavaScript ES6+, TypeScript, React 19, Next.js, Redux Toolkit, REST API, Git
- **Стоимость:** 1 800 000 сум/мес (или 11 200 000 сум при оплате за весь курс со скидкой 10%)
- **Результат:** 5 проектов в портфолио (интернет-магазин, соцсеть, CRM, дашборд аналитики, дипломный стартап)
- **Для кого:** С нуля и для продолжающих

## 2. Python & AI Engineering
- **Формат:** Офлайн / Онлайн
- **Длительность:** 8 месяцев
- **Стек:** Python 3.12, ООП, PostgreSQL, Django, FastAPI, Docker, LangChain, RAG-системы, интеграция OpenAI & Gemini API, Telegram Bots
- **Стоимость:** 2 100 000 сум/мес
- **Результат:** 4 реальных бэкенд и AI-проекта, развернутых на VPS с CI/CD
- **Для кого:** Для тех, кто хочет в бэкенд и современную AI-разработку

## 3. UI/UX Design & Product Design
- **Формат:** Офлайн / Онлайн
- **Длительность:** 5 месяцев
- **Стек:** Figma (Auto Layout, Design Systems, Variables), Research & CJM, Wireframing, Прототипирование, UI Kit, Principle, Кейсы на Behance
- **Стоимость:** 1 650 000 сум/мес
- **Результат:** 3 полноценных кейса на Behance (мобильное приложение, веб-сервис, дизайн-система)

## 4. Backend-разработка (Go / Golang & Microservices)
- **Формат:** Офлайн / Онлайн
- **Длительность:** 6 месяцев
- **Стек:** Golang, Concurrency, gRPC, PostgreSQL, Redis, Kafka, Docker, Kubernetes basics, Highload паттерны
- **Стоимость:** 2 300 000 сум/мес
- **Результат:** Микросервисная архитектура платежного шлюза и высоконагруженный сервис чатов

## 5. QA Automation (Python / JavaScript)
- **Формат:** Онлайн / Офлайн
- **Длительность:** 4 месяца
- **Стек:** Тест-дизайн, Postman, SQL, Selenium, Playwright, PyTest, CI/CD в GitHub Actions
- **Стоимость:** 1 500 000 сум/мес
- **Результат:** Автоматизированный тестовый фреймворк для Web и API
